# 售后反馈工作台

一个纯前端的问题反馈记录工具。打开网页就能记，**内容自动保存**，**截图直接 Ctrl+V 粘贴**，写完一键复制成标准模版文本，粘到群里就能用。

## 它解决什么问题

以前反馈一个问题要重复做这些事：翻上次的模版 → 重新敲门店名、加密狗、系统版本 → 一张张截图另存 → 再一张张上传 → 手写格式。

现在：

| 以前 | 现在 |
| --- | --- |
| 每次重新敲门店 / 加密狗 / 系统版本 | 点一下字段上的 📌 存为常用，之后新建记录**自动填好** |
| 截图要先另存为文件再上传 | 截图后直接在网页上 `Ctrl+V`，立即进附件区 |
| 随手关掉就丢了 | 每敲一个字都**自动存到本机**，关掉再开还在 |
| 手动排版模版格式 | 右侧**实时生成成稿**，一次复制直接粘群里 |
| 文字发完还要一张张补图 | 「复制图文」把文字 + 全部截图**合成一张长图**，粘贴一次就发完整条反馈 |
| 一张张发图 | 「打包下载」一键导出全部截图为 zip |

## 三种复制方式

| 按钮 | 得到什么 | 什么时候用 |
| --- | --- | --- |
| **复制文字** | 纯文本 | 需要对方能选中、复制里面的订单号 / 卡号 |
| **复制图文** | 文字 + 全部截图合成的**一张长图** | 发群里，一次粘贴搞定，最常用 |
| **长图** | 把长图存成 PNG 文件 | 想先检查排版，或剪贴板权限被拦时兜底 |

> **为什么是「合成一张长图」而不是「文字配 4 张图」？**
> 浏览器剪贴板一次只能放一张图，企业微信 / 微信也不支持一次粘贴「文字 + 多张图」。
> 合成一张长图是唯一能做到「粘贴一次、内容完整」的方式。
> 代价是图里的文字不能被对方选中复制 —— 如果研发需要复制订单号，请改用「复制文字」。

## 四套模版

顶部标签可切换，每套模版各自独立保存草稿，互不干扰：

1. **内部售后反馈** — 客户信息 / 加密狗 / 系统版本 / 设备 / 现象描述 / 实际情况 / 系统显示 / 差异异常 / 操作步骤 / 已尝试处理 / 影响范围 / 紧急程度 + 附件
2. **客户问题回复** — 问候语 → 引用问题 → 原因 → 解决方案 → 后续避免
3. **工单回复客户** — 含钉钉工单编号
4. **排查中回复** — 问题已反馈排查中，给客户先安抚

## 怎么用

- **粘贴截图**：截好图（Win + Shift + S 或 QQ/微信截图），在网页任意位置按 `Ctrl+V`。
- **存为常用**：填好门店名 / 加密狗 / 系统版本后，点字段标签右侧的 📌，以后新建自动带上。
- **复制发群**：右侧预览区点「复制全文」，再到群里粘贴。
- **发图**：缩略图右上角 📋 可把单张图复制到剪贴板直接粘进聊天窗口；「打包下载」导出全部。
- **找回旧记录**：右侧「历史记录」点一下即可继续编辑；支持关键词搜索。
- **备份 / 换电脑**：顶部「导出」生成一个 JSON 备份文件，「导入」可在另一台设备恢复（含图片）。

## 数据在哪

全部存在**你自己浏览器的 IndexedDB** 里，页面不上传任何数据，也没有后端。
换浏览器、换电脑、清空浏览器数据都会导致记录丢失 —— 重要内容请偶尔「导出」备份一次。

## 本地运行

因为浏览器对 `file://` 下的本地数据库有安全限制，**建议用本地服务器打开**：

```bash
# 任选其一
python -m http.server 8000
npx serve .
```

然后访问 `http://localhost:8000`。

线上访问 GitHub Pages 地址即可（HTTPS，功能完整）。

## 技术

无框架、无构建、无依赖 —— 只有 `index.html` / `styles.css` / `app.js` 三个文件。
ZIP 打包是自己实现的极简 store-only 写入器，不引第三方库。
